# learn-like-5

My personal, barrier-free digital notebook. 

Here, I break down complex concepts into simple stories, like I'm explaining them to a 5-year-old.

There are no fixed topics here. If I learn it today, or if it's something I already know and want to simplify, it goes here. It could be:
* Coding & Tech
* Physics & Math
* Academic topics
* Or absolutely anything under the sun!

## 🧠 The Rule of 5
If I can't explain it to a 5-year-old, I don't actually know it. This repo is my way of mastering everything by making it simple.
